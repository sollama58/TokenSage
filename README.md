# TokenSage

Understands Solana pump.fun memecoins: what a token's name, ticker, image, description and linked X/Twitter content *mean*, explained with evidence and confidence scores. No external AI APIs; deployed on Render via a Blueprint.

**Status:** research and planning. Start with [`PROJECT_GUIDE.md`](PROJECT_GUIDE.md).

- `docs/research/`: detailed research reports (pump.fun data, X access, non-AI understanding techniques, Render)
- `docs/reference/`: small, tested reference implementations to port into the codebase
